# Botium Toys Security Audit

## Overview
An internal security audit was conducted for Botium Toys, a small & fictional U.S. company with a growing market worldwide. I reviewed the IT manager's scope, goals, and risk assessment report to deliver a controls and compliance checklist with a recommendation to improve Botium's overall security posture.

## Approach
1. Reviewed given documents of the company's scope, goals, and risk assessment report.
2. Performed an internal audit of the company's security posture by completing a controls and compliance checklist.
3. Identified critical security risks and recommended a few best practices to the IT manager.

## Skills Demonstrated
- Security controls assessment
- NIST CSF application
- Risk prioritization
- Compliance evaluation
